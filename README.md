# FarmHubUI

UI สำหรับ Roblox (Lua/Luau) — เมนู ฟาร์ม / หาตัว / สวน / เพิ่ม FPS

## ฟีเจอร์
- หน้าฟาร์ม: เลือกโซน, เริ่มฟาร์ม, เก็บเพชร, เลือกไข่ (รายการไข่เปลี่ยนตามโซน)
- สวิตช์เปิด/ปิด, Dropdown, ปุ่ม
- ลากหน้าต่างได้, กด `RightControl` เพื่อซ่อน/แสดง

## วิธีใช้
ใส่ `FarmHubUI.lua` ใน `LocalScript` (StarterPlayerScripts) หรือรันผ่านตัวรันสคริปต์
